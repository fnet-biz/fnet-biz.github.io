# 有限会社エフネット Webサイト

公開URL: https://fnet-biz.github.io/

トップページには検索・AI認識向けのtitle、description、canonical、OGP、Organization構造化データを設定しています。`robots.txt`と`sitemap.xml`もリポジトリ直下へ配置しています。

## お問い合わせフォームの初回認証

お問い合わせフォームはFormSubmitを利用し、`fnet.businessdomain@gmail.com` へ送信します。

公開後にフォームを1回送信すると、同アドレスへFormSubmitの認証メールが届きます。メール内の認証リンクをクリックした後、もう一度テスト送信して受信を確認してください。認証が完了するまで問い合わせメールは配信されません。
